# Hackathon Requirements

## Core Architecture
- **Frontend**: Next.js (App Router, React, TypeScript, Tailwind CSS)
- **Backend**: Fastify (Node.js, TypeScript, Zod)
- **Database & Auth**: Supabase PostgreSQL
- **Shared Contracts**: Single source of truth for types/schemas between frontend and backend

## Development Rules
- Clean and professional GitHub repository
- Working, functional web application
- Proper disclosure of third-party libraries, APIs, frameworks, and AI tools
- No boilerplate plagiarism or unvetted templates
- Authoritative game logic runs exclusively on the backend
